Este arquivo existe para o `PRD.md` voltar a ser legível.

Um PRD é passagem de bastão: a sessão seguinte o lê para saber onde o trabalho
parou. Quando ele passou de 200 KB, lê-lo inteiro custava boa parte de uma
sessão — o instrumento criado para economizar trabalho passou a gastá-lo. O
corte foi feito em **07/09/2026**, no dia em que a fila de código fechou, que é
o momento mais barato: nada aqui dirige trabalho pendente.

**Ficou no PRD:** todos os IDs, com a decisão inteira e o status — nenhuma
referência do projeto quebra.
**Veio para cá:** o **motivo** de cada decisão de D-01 a D-53, que é a parte
longa e é história, mais o changelog das versões 1.0 a 5.9.

Para saber **por que** uma decisão antiga foi tomada, é aqui. Para saber **o
que** foi decidido e se ainda vale, é o PRD.
